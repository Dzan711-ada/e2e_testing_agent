# 新商城 Agent 路径（阶段 3）

在项目内运行：

```powershell
.\.venv\Scripts\python.exe main.py run --shop --query "测试登录和购物车，添加一本 Agent Handbook 并检查数量为 1"
```

使用既有 `.env` 的主／备用模型设置，不覆盖任何配置。PyCharm 可向 main.py 的运行参数加入 `run --shop`，再在控制台直接回车发送需求和澄清答复。已有 `demo`、外部网址旧路径和历史记录仍可使用。

新路径先实际观察本地商城各页面，再由设计角色规划需求来源、独立场景和链内检查点。执行角色仅从当前页面候选中选择目标；程序校验动作身份、字段用途、资源引用、唯一匹配及预算，并由 Playwright 检查预期结果。模型不决定最终通过状态。

本阶段仅使用可控商城和公开虚构的固定账号资源；账号、密码通过引用传给执行器，不作为角色输入。缺少业务答案时保留问题并阻塞；页面没有用户明确要求的能力时报告冲突。人工验证码和跨进程资源代理属于阶段 4，当前不宣称支持。

完整导出包括普通 Pytest、suite.json、身份清单与模型无关的支持模块；可用原 `main.py replay 运行目录` 重跑。首次失败和重跑分别记录；未生成完的场景保留 partial-plan.json，不作为完整脚本导出。

统一阶段验收：`python scripts/verify_stage.py --stage 3`。固定角色浏览器回归和真实模型专项分别留证；仅固定角色通过不足以满足 G3。
